## 📖 Overview

The **Web Calculator** is a lightweight, responsive, and fully functional calculator built entirely with standard web technologies. It provides a clean and intuitive interface for performing basic arithmetic operations right in your browser, without the need for any external dependencies or backend services.

## ✨ Key Features

*   **Basic Arithmetic Operations:** Supports addition (+), subtraction (-), multiplication (*), and division (/).
*   **Decimal Support:** Perform precise calculations with floating-point numbers.
*   **Error Handling:** Gracefully handles edge cases like division by zero (displays "Error").
*   **Backspace Functionality:** Easily correct mistakes without clearing the entire input.
*   **Clear functionality (C):** Reset the calculator to its initial state.
*   **Responsive Design:** Adapts nicely to different screen sizes.
*   **Secure Implementation:** Custom logic implementation avoiding the use of the risky `eval()` function.

## 🛠️ Tech Stack

*   **Frontend:**
    *   HTML5: Semantic structure.
    *   CSS3: Styling, layout (CSS Grid & Flexbox), and responsive design.
    *   Vanilla JavaScript: Core calculator logic and DOM manipulation.
*   **Backend:** None (Client-side only).

3.  **Run the project:**

## 🔐 Environment Variables

This project is entirely frontend-based and does **not** require any `.env` file or environment variables.

## 🕹️ Usage

1.  Open `index.html` in your browser.
2.  Click on the number and operator buttons to build your calculation.
3.  Click `=` to see the result.
4.  Use `C` to clear all inputs.
5.  Use `<` to backspace and delete the last entered digit.
